# OrganEasy

OrganEasy é uma plataforma SaaS modular para gestão empresarial.

## Arquitetura

- Django Core
- Django REST Framework
- SimpleJWT
- FastAPI
- PostgreSQL
- Redis
- Docker Swarm
- HAProxy
- Prometheus
- Grafana
- Loki
- Tempo

## Módulos planejados

- Kanban
- Chat
- Financeiro
- RH
- WMS
- TMS
- E-commerce
